# 🚀 3주차 - 로또

## 🎯 3주차 개인적 학습 목표

- 1주차, 2주차 피드백을 적극적으로 반영하는 것을 목표로 한다.
- 디자인 패턴(MVC)을 적용해본다.
- Java Enum을 적극적으로 활용한다.
- 기능 단위 테스트 케이스를 전부 작성해보기 (모든 메서드 목표)

-----

## 📝 프로젝트 설명 (우아한테크코스 3주차)

간단한 로또 발매기를 구현한다.
관련 함수를 묶어 클래스를 만들고, 객체들이 협력하여 하나의 큰 기능을 수행하도록 한다.
클래스와 함수에 대한 단위 테스트를 통해 의도한 대로 정확하게 작동하는 영역을 확보한다.

-----

## ⚙️ 기능 요구사항 정리

1. 로또 번호의 숫자 범위는 1\~45까지이다.
2. 로또 하나를 발행하면 중복되지 않은 6개 숫자와 보너스 숫자 1개를 뽑는다.
3. 당첨은 1등부터 5등까지 있다.
    - **1등:** 6개 번호 일치 / 2,000,000,000원
    - **2등:** 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - **3등:** 5개 번호 일치 / 1,500,000원
    - **4등:** 4개 번호 일치 / 50,000원
    - **5등:** 3개 번호 일치 / 5,000원
4. 로또 1장의 가격은 1,000원으로, 구입 금액을 입력하면 금액만큼 로또를 발행한다.
5. 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
6. 잘못된 값을 입력하였을 경우 `IllegalArgumentException`을 발생시키고 `[ERROR]`로 시작하는 에러 메시지를 출력 후, 그 부분부터 입력을 다시 받는다.

-----

## 🔢 로직 순서

1. 로또 구입 금액을 입력받는다. (1,000원 단위로 나누어 떨어지지 않으면 에러)
2. 발행한 로또 수량 및 번호를 출력한다. (로또 번호는 오름차순으로 정렬)
3. 당첨 번호를 사용자에게 입력받는다. (구분은 쉼표 `,`)
4. 당첨 번호와 중복되지 않는 보너스 번호 1개를 입력받는다.
5. 당첨 내역을 출력한다.
6. 총 수익률을 출력한다. (소수점 둘째 자리에서 반올림 → 소수점 한 자리)

## 🏛️ 3주차 미션 개발 구조 (MVC)

MVC 패턴을 적용해보자.
3주차 미션은 사용자 인터페이스와 데이터 그리고 비즈니스 로직이 뚜렷하기에 MVC 디자인 패턴으로 개발해보는 게 좋을 거 같다.
사실 2주차까지 단순한 클래스 분리로 개발했을 때도 클래스명에 따른 기능 분리라 개발하는 데 있어, 구조가 없어 불안한 면도 있었다.
특히 모델과 컨트롤러의 역할을 더 쪼개어 **Service 레이어**를 추가하여 만들 예정이다.

### 데이터 흐름

```
view -> Controller -> service -> domain -> service -> controller -> view
```

### 역할 분리

- **Model (Domain)**: 로또, 당첨번호, 당첨통계
- **Service**: 로또 발급, 당첨 결과 계산, 입력값 밸리데이션
- **View**: 로또 구매 금액 입력, 당첨 번호 입력, 보너스 번호 입력
- **Controller**: 입출력 흐름 및 예외 처리, 재시도
